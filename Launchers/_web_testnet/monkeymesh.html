MonkeyMesh

Mine MESH on a home PC. Designed for ordinary hardware. Fusion MeshHash coordinates your CPU and GPU so they find one block together. Each find pays 45 MESH to your wallet and 5 MESH to nodes.

How a block is found

One Fusion solution. GPU does the wave. CPU seals that ticket. They fuse into one block. From height 50000 the finder gets 90% (45 MESH) in one pay line. Nodes get 10%. Official miners refuse CPU-only after height 29,000.

90%

Finder

45 MESH to the miner wallet. CPU and GPU must both be in the digest. A one-sided farm cannot skip a chip and still produce a valid block.

10%

Network nodes

5 MESH per block, only for attested useful work (relay, routing, snapshots). Idle nodes earn nothing.
